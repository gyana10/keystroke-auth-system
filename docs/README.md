# ⌨️ AI-Powered Keystroke Authentication & Data Engineering System

An end-to-end Behavioral Biometrics Authentication Platform that combines Machine Learning, Anomaly Detection, Data Engineering, ETL Pipelines, Data Warehousing, FastAPI, and Streamlit to authenticate users based on their unique typing patterns.

# 📌 Project Overview

Traditional authentication systems rely only on passwords, which can be stolen, shared, or compromised. This project introduces an AI-powered authentication framework that analyzes a user's typing behavior (Keystroke Dynamics) to determine whether the user is genuine or suspicious.

The system integrates Machine Learning and Data Engineering to create a complete production-style pipeline, including data ingestion, warehousing, analytics, model inference, and real-time prediction.

# 🧠 Machine Learning Pipeline

The authentication engine uses an ensemble learning architecture:

### Base Models

* Random Forest Classifier
* Support Vector Machine (SVM)
* Logistic Regression

### Meta Model

* Stacking Ensemble Classifier

### Anomaly Detection

* Isolation Forest

The final prediction is generated by combining the outputs of multiple models and evaluating anomaly scores.
